# TicTacToe 
A Python implementation of the classic Tic-Tac-Toe game.

## Description
This program simulates a game of Tic-Tac-Toe using two computer-controlled players.

At the start of each game, a random dice roll determines which player moves first. The players are assigned the symbols "X" and "O". The player assigned "X" is designated as Player 1.

After each move, the current game board is displayed and the program checks whether a winning condition has been reached.

## Game Rules
Two players participate in the game.
A random roll determines who goes first.
Players take turns placing their symbols on the board.
A player wins by placing three symbols in a row, column, or diagonal.
If all squares are filled without a winner, the game ends in a draw.

## Requirements
Python 3.x

## Running the Program
python TicTacToe.py
